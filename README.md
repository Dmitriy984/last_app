#  CineVault — ваша персональная киноплатформа

CineVault — это веб-приложение для просмотра каталога фильмов, добавления их в избранное и управления личной коллекцией. **Без покупок, без рекламы, только кино.**

Проект выполнен на React 18 с использованием React Router 6, Vite и Tailwind CSS (с кастомными glassmorphism‑стилями). Данные хранятся в `localStorage`, поэтому для работы не требуется серверная часть.

---

##  Возможности

- **Каталог фильмов** — просматривайте список фильмов с постером, годом, длительностью и рейтингом.
- **Детальная страница** — полная информация: описание, режиссёр, актёры, жанры.
- **Фильтрация по жанрам** — выбирайте жанр, чтобы отфильтровать подходящие фильмы.
- **Поиск по названию** — найдите нужный фильм за секунды.
- **Регистрация и вход** — создайте аккаунт, чтобы сохранять избранное.
- **Избранное (Watchlist)** — добавляйте и удаляйте фильмы из своей библиотеке
- **Профиль** — просмотр избранного и изменение имени.
- **Современный UI** — плавные анимации.
- **Адаптивный дизайн** — просмотр на любых устройствах.
